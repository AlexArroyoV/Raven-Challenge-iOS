## 🎯 Sobre el Challenge

Hemos preparado un **desafío técnico** diseñado para evaluar tus habilidades como desarrollador iOS. Se trata de un proyecto real en SwiftUI que actualmente **no funciona correctamente** y necesita que lo analices y corrijas.

### ¿Qué vas a hacer?

Trabajarás con una aplicación iOS que consume la API del New York Times para mostrar artículos populares. La app tiene arquitectura limpia, usa SwiftData para persistencia, y está construida con las mejores prácticas... o al menos debería estarlo 😉

**Tu misión**: Identificar y corregir todos los errores para que la aplicación funcione perfectamente.

---

## 📋 Detalles del Challenge

### Tecnologías Involucradas
- Swift 5.0+
- SwiftUI
- SwiftData
- Async/Await
- Clean Architecture (MVVM)

### Requisitos Técnicos
- Xcode 16.1 o superior
- macOS con soporte para iOS 18.1+
- Aproximadamente 2-4 horas de tu tiempo

### Tipos de Errores que Encontrarás
El código contiene diversos tipos de errores que pondrán a prueba diferentes habilidades:
- ✅ Errores de compilación
- ✅ Errores de runtime
- ✅ Problemas de lógica
- ✅ Issues de persistencia de datos
- ✅ Memory management
